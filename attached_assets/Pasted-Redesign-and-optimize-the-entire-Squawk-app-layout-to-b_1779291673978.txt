Redesign and optimize the entire Squawk app layout to behave like Instagram’s fully responsive UI across mobile phones, tablets, laptops, and desktop PCs.

MAIN GOAL:
Make the app automatically adapt to every screen size so all frames, buttons, feeds, reels, stories, comments, modals, and navigation fit perfectly without:

* buttons getting cut off
* text overlapping
* frames overflowing
* icons hiding
* horizontal scrolling
* broken layouts

The app should feel smooth and premium on both mobile and desktop exactly like Instagram.

RESPONSIVE LAYOUT SYSTEM:
Create a fully adaptive responsive layout system using:

* Flexbox
* CSS Grid
* responsive containers
* fluid spacing
* dynamic sizing

Avoid fixed widths/heights unless necessary.

Use:

* max-width
* min-width
* width: 100%
* responsive padding/margins
* viewport units
* flexible grids
