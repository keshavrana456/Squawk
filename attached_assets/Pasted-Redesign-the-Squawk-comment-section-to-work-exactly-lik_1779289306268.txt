Redesign the Squawk comment section to work exactly like Instagram’s modern slide-up comments UI with smooth animations, realtime interactions, and responsive mobile experience.

MAIN GOAL:
Instead of opening comments inside the post card or another page, make comments open in a separate slide-up bottom sheet/modal just like Instagram.

COMMENT MODAL BEHAVIOR:

* Clicking the comment icon should:

  * open a fullscreen/half-screen bottom sheet
  * smoothly slide up from the bottom
  * darken/blur background behind it
* User should still partially see the post behind the comments modal.
* Add smooth closing animation when swiping down or tapping outside.

MOBILE EXPERIENCE:

* On mobile:

  * comments modal should feel native and smooth
  * support drag-down gesture to close
  * support touch scrolling
  * keyboard should not cover input field
* On desktop:

  * modal should appear centered or bottom aligned elegantly

* close button

* scrollable comments list
* nested replies

Bottom Section:

* fixed comment input bar
* emoji button
