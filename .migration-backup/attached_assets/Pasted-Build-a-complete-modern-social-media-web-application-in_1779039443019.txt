Build a complete modern social media web application inspired by Instagram, TikTok, and Discord. The platform should feel like a real-world production-ready startup product with premium UI/UX, smooth animations, realtime features, and fully working authentication.

The app must be fully responsive, mobile-first, visually stunning, and highly interactive.

==================================================
AUTHENTICATION SYSTEM
==================================================

Create a fully working authentication system.

LOGIN / SIGNUP FLOW:
1. User enters:
   - phone number OR email

2. Send OTP verification code
   - real OTP UI
   - animated verification screen
   - countdown timer
   - resend OTP button
   - smooth validation

3. After successful OTP:
   - ask user to create username
   - upload profile photo
   - add bio
   - select interests
   - create account

4. Automatically generate:
   - user profile
   - user ID
   - personal feed
   - suggested creators

AUTH FEATURES:
- phone login
- email login
- OTP verification
- persistent sessions
- logout system
- secure authentication
- protected routes
- onboarding flow
- loading animations
- realtime validation
- forgot password support
